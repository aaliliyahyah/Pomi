# Noto Serif peso fallback

Lora does not contain U+20B1 (₱). This normal variable Noto Serif subset provides
only that character at weights 400–700. It is unmodified from Google Fonts and
is exposed as "Noto Serif Peso" in CSS with `unicode-range: U+20B1`.
