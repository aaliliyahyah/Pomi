# DM Sans for Pomi

Normal variable font, locally bundled for offline use. Source: https://github.com/google/fonts/tree/main/ofl/dmsans
License: SIL Open Font License 1.1 (OFL.txt). Includes optical size and weight axes; CSS uses weights 400–700 and automatic optical sizing.

DM Sans is used for body text and controls. Headings and financial figures use the bundled Lora and Noto Serif Peso faces.
