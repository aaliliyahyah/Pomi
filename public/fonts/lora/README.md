# Lora for Pomi

Lora by Cyreal, selected for its soft calligraphic serif forms and screen readability.

- Project: https://github.com/cyrealtype/Lora-Cyrillic
- License: SIL Open Font License 1.1; see [OFL.txt](OFL.txt).
- Distribution: Google Fonts Lora v37, normal variable weights 400–700.
- Downloaded: 2026-11-17.
- Files are unmodified Google Fonts WOFF2 subsets. The Google Fonts Latin-ext Unicode range advertises U+20B1 (₱), but Lora does not contain that glyph. The CSS excludes it and uses the separately licensed, peso-only Noto Serif subset in `../noto-serif-peso/`.
- Stylesheet: https://fonts.googleapis.com/css2?family=Lora:wght@400..700&display=swap
